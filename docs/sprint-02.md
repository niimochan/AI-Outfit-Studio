# Sprint 02 — Asset & Project Foundation

## Goal

VRMビューアを単体デモから、作業を保存・再開できるアプリケーション基盤へ進化させる。

## Definition of Done

- [x] 新規プロジェクトを作成できる
- [x] プロジェクト名を編集できる
- [x] `.aos`として保存できる
- [x] 既存`.aos`を開ける
- [x] 名前を付けて保存できる
- [x] 未保存状態を表示できる
- [x] 未保存のまま終了する際に警告できる
- [x] 最近使用したプロジェクトを表示できる
- [x] VRMのリンク情報を保存・再読み込みできる
- [x] 参考画像を複数追加・表示・削除できる
- [x] VRoidテンプレート画像を複数追加・表示・削除できる
- [x] 透過PNGをチェッカーボード上で確認できる
- [x] 画像をInspectorとViewportオーバーレイで確認できる
- [x] ファイル操作にWindowsネイティブダイアログを使う
- [x] VRM削除時に3Dリソースを解放できる
- [x] メニューバーとキーボードショートカットを追加する

## Project format scope

Version 0.2の`.aos`はリンク型です。

保存対象：

- プロジェクトID・名前・日時
- アプリとスキーマのバージョン
- VRMのファイルパスとメタデータ
- 参考画像のファイルパスとメタデータ
- テンプレートのファイルパスとメタデータ

未実装：

- アセット本体の埋め込み
- 自動バックアップ
- 相対パスへの変換
- サムネイルキャッシュ
- Undo / Redo

## Verification checklist for Windows

1. `npm run dev`で起動する
2. VRMを追加し表示を確認する
3. 参考画像を2枚以上追加する
4. 透過PNGテンプレートを追加する
5. プロジェクト名を変更する
6. `.aos`として保存する
7. アプリを閉じ、再起動する
8. 最近使用したプロジェクトまたは「開く」から再読み込みする
9. VRMと画像が復元されることを確認する
10. アセット変更後、未保存警告が出ることを確認する
