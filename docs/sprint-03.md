# Sprint 03 — Material Preview Foundation

## Goal

VRMに含まれるマテリアルを解析し、登録済みのVRoidテンプレート画像を3Dモデルへリアルタイム適用して確認できるようにする。

## Implemented

- VRMロード後にユニークなマテリアルを抽出
- マテリアル名、シェーダー型、利用メッシュ数、元テクスチャ有無を表示
- マテリアルごとの選択と編集状態表示
- テンプレート画像をBase Colorテクスチャとしてリアルタイム適用
- 色、不透明度、Repeat X/Y、Offset X/Yの編集
- 選択マテリアルまたは全マテリアルの復元
- 適用テクスチャのGPUリソース管理と差し替え時の破棄
- `.aos` Schema 2へマテリアルオーバーライドを保存
- Schema 1プロジェクトの自動マイグレーション

## Acceptance criteria

1. VRMロード後にマテリアル一覧が表示される
2. テンプレートを選ぶと選択マテリアルの見た目が変わる
3. 色・不透明度・UV変換が即時反映される
4. 「選択を元に戻す」「全て元に戻す」が機能する
5. 保存した`.aos`を開き直すと設定が再適用される
6. テンプレート差し替えやVRM削除後もエラーやGPUリソースリークが起きない

## Known limitations

- 現段階はプレビュー機能であり、VRMまたはVRoid用PNGへの書き戻しは行わない
- Base Colorテクスチャのみを対象とし、Normal、Emission、Shade、Rimなどは未対応
- マテリアルの安定識別子はVRM内の走査順を基準としている
- Undo / Redoは未実装
