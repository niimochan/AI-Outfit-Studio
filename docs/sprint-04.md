# Sprint 04 — Texture Editor Foundation

## Goal

Photoshopを必要とせず、VRoidテンプレート上で画像を非破壊編集し、透過PNGと3Dプレビューへ接続できる最小の2D編集基盤を完成させる。

## Implemented

- テンプレート画像の実寸を使用した編集キャンバス
- 画像レイヤーの追加、削除、表示切替、並び替え
- 不透明度と合成モード
- 位置、非等方スケール、回転
- 円形消しゴムストロークの記録と再描画
- テンプレートAlphaマスク
- キャンバスのズーム、パン、フィット
- ドキュメント単位のUndo / Redo
- Canvas合成結果をPNG Blobへ変換
- Electronネイティブ保存ダイアログによるPNG書き出し
- 編集結果を仮想テクスチャとしてMaterial Previewへ供給
- `.aos` Schema 3へTexture Documentsを保存
- Schema 1 / 2の自動マイグレーション

## Acceptance criteria

1. テンプレートから2D編集ドキュメントを作成できる
2. 参考画像をレイヤーとして追加できる
3. レイヤーを移動・拡縮・回転できる
4. 表示・不透明度・描画順・合成モードが機能する
5. 消しゴム操作をUndo / Redoできる
6. Alphaマスクでテンプレート外が透明になる
7. PNGを書き出せる
8. 編集結果をVRMマテリアルへ適用できる
9. `.aos`を開き直して編集状態が復元される
10. Schema 2プロジェクトを正常に開ける

## Known limitations

- 自由選択、投げ縄、矩形選択は未実装
- ブラシペイントと色塗りは未実装
- レイヤーマスクは消しゴムストロークのみ
- 変形ハンドルは未実装し、数値入力とドラッグ移動を使用
- 4Kキャンバスの大量同時編集は今後最適化が必要
